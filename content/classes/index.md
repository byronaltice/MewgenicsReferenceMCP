# Classes

**Classes** are an integral property of adventuring [cats](/wiki/Cats "Cats"), which apply [stat](/wiki/Stat "Stat") modifiers and determine which abilities are offered from post combat rewards. Newborn cats start out [![Collarless Icon.svg](images/Collarless_Icon.svg)](/wiki/Collarless "Collarless") [Collarless](/wiki/Collarless "Collarless"), but may become a different class by assigning the corresponding collar (if it is unlocked) when beginning a new adventure. If no collar is assigned, the cat will receive no stat modifiers and will only be offered Collarless abilities which are offered to all cats.

Initially, only five classes are available: [![Collarless Icon.svg](images/Collarless_Icon.svg)](/wiki/Collarless "Collarless") [Collarless](/wiki/Collarless "Collarless"), [![Fighter Icon.svg](images/Fighter_Icon.svg)](/wiki/Fighter "Fighter") [Fighter](/wiki/Fighter "Fighter"), [![Hunter Icon.svg](images/Hunter_Icon.svg)](/wiki/Hunter "Hunter") [Hunter](/wiki/Hunter "Hunter"), [![Mage Icon.svg](images/Mage_Icon.svg)](/wiki/Mage "Mage") [Mage](/wiki/Mage "Mage"), and [![Tank Icon.svg](images/Tank_Icon.svg)](/wiki/Tank "Tank") [Tank](/wiki/Tank "Tank"). Additional classes are unlocked by beating areas for the first time and then talking to [![NPC Butch Icon.svg](images/NPC_Butch_Icon.svg)](/wiki/Butch "Butch") [Butch](/wiki/Butch "Butch"), who will award that area's corresponding collar.
